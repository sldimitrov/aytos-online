# Айтос Онлайн — Brand Guide

Reference file for any AI coding agent (Claude Code, Cursor, Lovable, etc.) or human working on this project. Follow this for consistent styling across the website, social media, and print materials.

## 1. Positioning

**Name:** Айтос Онлайн (Aytos Online)

**What we do:** We help small local businesses in Aytos, Bulgaria (cafes, salons, gyms, boutiques, auto services) get found, trusted, and chosen online — through websites, Google review setup, and general online visibility.

**Tagline:** Правим бизнеса ви видим. ("We make your business visible.")

**Tone of voice:** Warm, direct, local, no jargon. Talk like a helpful neighbor, not a corporate agency. Short sentences. No buzzwords like "digital transformation" or "synergy." Always low-pressure — offer, don't push ("без ангажимент" / "no obligation" is a recurring phrase).

**Business description (canonical, use as-is when a description is needed):**
> Правим бързи, красиви и работещи сайтове за малки бизнеси — кафенета, салони, фитнеси, бутици и сервизи. Без сложни процеси и скрити такси.

## 2. Logo & Icon

**Concept:** A minimal geometric eagle mark. Aytos's historic fortress was known as *Aetos* — Greek for "eagle" — so the icon ties the brand to the town's own history rather than using a generic tech symbol. A small pulse/signal dot at the wingtip represents "going online."

**Variants:**
- Primary lockup: icon + "АЙТОС ОНЛАЙН" wordmark + tagline (for headers, letterhead, print)
- Icon-only: for avatars/favicons — comes in dark-background gold, light-background rust, and monochrome cream versions
- Horizontal lockup: icon + wordmark side-by-side (for site header/nav bar)

**Clear space:** Keep padding around the icon at least equal to the height of one wing on all sides. Don't crowd it against edges or other elements.

**Don't:**
- Don't recolor the eagle outside the approved palette below
- Don't stretch or skew the mark
- Don't place the gold icon on light backgrounds without switching to the rust variant (contrast issue)

## 4. Typography

**⚠️ Important font note:** Poppins does **not** include Cyrillic glyphs. Since all primary content is in Bulgarian, do not rely on Poppins alone for Cyrillic text — it will silently fall back to a mismatched system font and break the visual consistency.

**Recommended stack:**
- **Cyrillic-safe display/headline font:** `Carlito` (rounded, humanist sans-serif, full Cyrillic support, metric-compatible with Calibri) — weights: Regular, Bold
- **Alternative if a webfont is preferred:** `Montserrat`, `PT Sans`, or `Manrope` — verify Cyrillic coverage before using any new font (check via Google Fonts' language support tab, or test render Cyrillic text directly)
- **Body text:** `Inter` or `Carlito` at Regular/Medium weight — confirm Cyrillic glyphs are present in whichever is used

**Rule of thumb for agents:** before adopting any new font in this project, verify it explicitly supports Cyrillic (`U+0400–04FF` range) — don't assume from the font's popularity or name alone.

## 5. Voice Examples (for copywriting)

Use these as tone reference when generating new copy (Instagram captions, outreach messages, site copy):

- "Видях страницата на [Business] — [specific, genuine observation]. Правя уебсайтове за фирми и си помислих, че бихте имали интерес от [specific benefit]."
- "Ако желаете, мога да ви покажа безплатно примерна визия — без ангажимент."
- Always personalize outreach with something specific noticed about the business — never generic mass-message language.
