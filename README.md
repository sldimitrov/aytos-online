# Aytos Online

Create a clean, modern one-page portfolio/landing site for a local 

web design freelance duo based in Aytos, Bulgaria, targeting small 

local businesses (cafes, salons, gyms, boutiques, auto services, 

manufacturers).

Sections needed:

1. Hero: Bold headline like "Уебсайтове, които печелят повече клиенти 

   за бизнеса ви в Айтос" with a short subheading and a CTA button 

   "Безплатна консултация"

2. Problem/value section: 3 short cards — "Нямате сайт?", "Сайтът ви 

   е остарял?", "Нямате онлайн отзиви?" each with 1-2 sentence fix

3. Services: Website design, Google review QR setup, online booking 

   integration, SEO basics — as simple icon + text cards

4. Portfolio/mockups: Grid placeholder for 3-4 example project cards 

   (image + business name + short result)

5. About: Two-person team, based in Aytos, personal local approach

6. Contact: Simple form (name, business, message) + Instagram/Facebook 

   link + phone

Style: dark background with one warm accent color, modern sans-serif 

typography, generous whitespace, mobile-first, subtle hover animations 

on cards. Bulgarian language throughout. Keep it fast-loading and simple 

— no heavy animations.
